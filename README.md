# 🎮 Typing Hero

A neon-inspired arcade typing game built with HTML, CSS and vanilla JavaScript. Test your typing speed, build streaks, improve your accuracy and beat your personal best.

## 🎯 About

Typing Hero turns typing practice into an arcade-style experience. Instead of traditional typing exercises, players take on timed challenges, type their way through words and compete against their own high scores.

The project combines a futuristic arcade aesthetic with simple, accessible gameplay, creating a typing game that's designed to be both challenging and enjoyable.

## ✨ Features

- 🎮 **Three difficulty levels:** Choose between Warm Up, Headliner and Encore.
- ⏱️ **Timed gameplay:** Complete each round within 60 seconds.
- 🎯 **Four-lane gameplay:** Type words as they appear across the game.
- 🔥 **Streak system:** Build consecutive correct answers and keep your momentum going.
- 🏆 **Scoring system:** Earn points as you play and aim for a new personal best.
- 📊 **Performance tracking:** Monitor your WPM, accuracy and overall performance.
- 💡 **Typing coach:** Get tips to help improve your typing.
- 🎵 **Sound controls:** Toggle game audio to suit your preferences.
- 📅 **Daily Mix:** Take on additional daily typing challenges.
- 👤 **Player profile:** Keep track of your progress with a locally saved profile.
- 📈 **Session history:** Review your recent games, personal best and total runs.
- 🔄 **Replay:** Jump straight back into another round when you've finished.

## 🕹️ How to Play

1. Launch Typing Hero in your browser.
2. Select your preferred difficulty.
3. Start a round and type the words as they appear.
4. Build streaks by typing correctly and quickly.
5. Earn points, monitor your accuracy and try to beat your personal best.
6. Play again and keep improving!

## 🛠️ Built With

- **HTML5** — Game structure and interface.
- **CSS3** — Styling, layout, animations and visual effects.
- **JavaScript (ES6+)** — Gameplay, scoring, timing and player progress.
- **LocalStorage** — Persistent player statistics and settings.

No frameworks or game engines are required.

## 🚀 Getting Started

You can run Typing Hero locally without installing any dependencies.

### Prerequisites

- A modern web browser.
- Git (optional, if cloning the repository).
- A code editor such as Visual Studio Code (optional).

### Installation

Clone the repository:

```bash
git clone https://github.com/MattWill19/typing-hero.git
```

Navigate to the project directory:

```bash
cd typing-hero
```

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

## 💾 Player Progress

Typing Hero uses your browser's LocalStorage to save player information and progress.

Your saved data is stored locally in your browser, so it isn't automatically synchronised between devices or browsers.

Clearing your browser's site data may remove your saved progress.
